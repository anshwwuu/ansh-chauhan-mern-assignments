# Assignment 3 — Complex Table

A CSS-variable timetable with semantic table sections, 20 body rows, 10 columns, colspan and rowspan.

## How to run
Open the main HTML file in a browser, or use VS Code Live Server.

## What I learned
- Structuring pages with semantic HTML.
- Styling and layout with CSS.

## One challenge
Keeping the table readable on small screens while preserving its 10-column structure; the wrapper allows horizontal scrolling.
