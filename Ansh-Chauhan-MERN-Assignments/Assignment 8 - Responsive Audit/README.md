# Assignment 8 — Responsive Audit

A responsive campus store based on the earlier product-grid project. It includes 768px and 480px breakpoints and fluid grid columns.

## How to run
Open the main HTML file in a browser, or use VS Code Live Server.

## What I learned
- Structuring pages with semantic HTML.
- Styling and layout with CSS.

## One challenge
Checking navigation wrapping, card width, font size and horizontal overflow at desktop, tablet and mobile widths.

## Responsive audit checklist
- [ ] Desktop: inspect at 1280px wide.
- [ ] Tablet: inspect at 768px wide.
- [ ] Mobile: inspect at 390px wide.
- [ ] Confirm no horizontal page scrolling.
- [ ] Confirm links and buttons have comfortable spacing.
- [ ] Save screenshots from DevTools for submission if requested.

Browser testing must be completed locally in DevTools before submission; this checklist is provided for that final verification.
